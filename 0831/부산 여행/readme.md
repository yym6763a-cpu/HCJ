# 🌊 BUSAN TRAVEL 3박 4일 가이드 (釜山3泊4日モデルコース)

> **"바다와 시장, 부산을 맛보다."**  
> **「海と市場、釜山を味わう。」**

일본인 관광객을 대상으로 부산의 바다, 대표 먹거리, 로컬 시장, 야경을 균형 있게 구성한 **3박 4일 여행 코스 가이드 웹페이지**입니다.  
한국어와 일본어 다국어 토글, Google Maps 연동, 브라우저 로컬 스토리지를 활용한 언어 설정 유지를 지원합니다.

## ✨ 주요 기능

- **원클릭 다국어 전환 (KO / JA)**: 상단 네비게이션 버튼을 통해 페이지 새로고침 없이 한국어/일본어로 화면 텍스트 실시간 토글
- **언어 설정 유지 (LocalStorage)**: 사용자가 선택한 언어 모드(`ko` 또는 `ja`)를 브라우저에 저장하여 재방문 시 자동 복원
- **구글 지도 연동 (Google Maps Direct Link)**: 각 여행지 카드마다 Google Maps 검색 파라미터 링크를 배치하여 현장 길찾기 편의성 극대화
- **반응형 웹 디자인**: 모바일 뷰포트 최적화, 스무스 스크롤링, 상단 고정 네비게이션(Glassmorphism 적용) 및 플로팅 상단 이동 버튼(`Back to top`)
- **하이브리드 호스팅 지원**: 정적 웹 호스팅(GitHub Pages)은 물론 **Google Apps Script(Web App)** 환경에서도 정상 작동하도록 설계
