## ✨ 주요 기능

- **인터랙티브 일정 탭**: JavaScript 기반의 탭 인터페이스를 통해 DAY 1부터 DAY 4까지 일자별 타임라인을 끊김 없이 전환
- **원페이지 부드러운 스크롤**: 상단 네비게이션 및 CTA 버튼 클릭 시 해당 섹션으로 부드럽게 이동 (`scroll-behavior: smooth`)
- **반응형 웹 디자인**: 모바일, 태블릿, 데스크톱 등 기기 해상도에 맞춰 그리드 구조가 자동으로 재배치되는 반응형 레이아웃
- **QR 코드 바로가기**: 모바일 기기로 화면을 스캔해 즉시 접속하고 저장할 수 있는 동적 QR 코드 탑재
- **Google Apps Script(GAS) 최적화**: GAS의 `HtmlService.createTemplateFromFile` 환경과 완벽히 호환되는 단일 HTML 구조
