# 🏛️ 경주 1박 2일 팀 MT 가이드 (慶州1泊2日チームMT)

> **"천년 신라의 도시에서 보내는 짧고 알찬 1박 2일"**  
> **「千年新羅の都で過ごす、短くも充実の1泊2日」**

한국어와 일본어 다국어 전환을 지원하며, 탭 기반 세부 타임라인, 숙소 비교 분석, QR 바로가기 링크를 제공하는 단일 페이지 웹 가이드 프로젝트입니다.

## ✨ 주요 기능

- **실시간 다국어 토글 (KO / JA)**: `data-ko`, `data-ja` 속성 및 JavaScript 상태 제어를 통해 새로고침 없이 한국어/일본어 화면 전환
- **인터랙티브 타임라인 탭**: 일자별(Day 1, Day 2) 동적 렌더링으로 일정 및 카테고리(숙박·관광·식사·액티비티) 확인
- **반응형 갤러리 그리드**: CSS Grid를 활용하여 데스크톱과 모바일 환경에 최적화된 유적지 갤러리 배치
- **숙소 옵션 비교 카드**: 보문단지 인근 독채 펜션/글램핑과 리조트/콘도형 숙소의 가격대, 적정 인원, 주요 시설 비교
- **온/오프라인 연동 QR 섹션**: 현장에서 모바일 기기로 즉시 접속할 수 있는 단축 URL QR 코드 내장
