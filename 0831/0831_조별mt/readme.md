## ✨ 주요 기능 및 인터랙션

- **감성적 풀스크린 히어로**: CSS 애니메이션 기반의 별빛 점멸, 달빛 글로우, 모닥불 및 반딧불 효과, 첨성대와 왕릉 능선 SVG 실루엣 렌더링
- **마우스 인터랙션 (패럴랙스)**: 데스크톱 화면에서 마우스 이동 방향에 맞춘 부드러운 히어로 레이어 패럴랙스
- **클릭 불꽃 파티클 효과**: HTML5 Canvas와 `requestAnimationFrame`을 활용한 불꽃 링 및 이모지 버스트 애니메이션 (성능을 고려한 스프라이트 사전 캐싱 적용)
- **부드러운 스크롤 내비게이션**: 상단 스티키 바 및 히어로 CTA 버튼 클릭 시 헤더 높이를 보정한 스무스 스크롤링
- **스크롤 등장 애니메이션**: `IntersectionObserver`를 활용한 카드별 스크롤 트리거 인터랙션
- **모바일 최적화**: 1단 그리드 전환, 동적 뷰포트(`dvh`), 폰트 스케일링을 반영한 반응형 UI

## 📂 프로젝트 디렉토리 구조

외부 번들러나 빌드 도구 없이 단일 정적 파일 또는 모듈화된 정적 웹 구조로 즉시 실행할 수 있습니다.

```bash
gyeongju-mt-guide/
├── index.html            # 메인 HTML (구조, 인라인 스타일 및 스크립트 포함)
├── README.md             # 프로젝트 설명 문서
└── (assets/)             # 외부 리소스 분리 시 (선택 사항)
    ├── css/
    │   └── style.css     # 분리된 스타일시트
    └── js/
        └── main.js       # 캔버스 파티클 및 스크롤 인터랙션 스크립트
