# 🎬 Media Portfolio Website

다양한 미디어 콘텐츠(영상, 이미지, 디자인, 프로젝트 등)를 효과적으로 전시하고 소개하기 위해 제작된 **미디어 포트폴리오 웹사이트**입니다.

---

## ✨ 주요 기능 (Key Features)

- 🎨 **포트폴리오 갤러리 (Media Gallery)**
  - 이미지 및 영상 작품을 깔끔한 그리드 레이아웃으로 시각화
  - 마우스 호버(Hover) 효과를 통한 상세 정보 및 작업 설명 제공
- 📱 **반응형 웹 디자인 (Responsive Web Design)**
  - 데스크톱, 태블릿, 모바일 등 모든 기기 화면 크기에 최적화된 레이아웃 제공
- 🙋‍♂️ **자기소개 및 프로필 (About Me)**
  - 작업자 소개, 보유 기술 스택, 커리어 및 경력 사항 안내
- 📩 **문의하기 및 소셜 링크 (Contact & Social Links)**
  - 작업 문의를 위한 연락처 정보 및 GitHub, LinkedIn, Instagram 등 SNS 연동

## 📁 파일 구조 (File Structure)

```text
.
├── mediaportfolio.html     # 메인 포트폴리오 HTML 파일
├── css/                    # (선택) 스타일시트 폴더
│   └── style.css
├── js/                     # (선택) 자바스크립트 폴더
│   └── main.js
└── assets/                 # (선택) 이미지 및 미디어 에셋 폴더
    └── images/
```

## 🚀 실행 및 대화형 테스트 (Getting Started)

### 1. 프로젝트 다운로드 / 클론
```bash
git clone https://github.com/your-username/media-portfolio.git
cd media-portfolio
```

### 2. 실행 방법
- 별도의 백엔드 서버 없이 `mediaportfolio.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 실행합니다.
- Visual Studio Code 사용자라면 **Live Server** 확장을 사용하여 로컬 개발 서버 환경에서 실행할 수 있습니다.
