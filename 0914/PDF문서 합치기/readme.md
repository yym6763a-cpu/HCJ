# 📄 PDF Merger (PDF 병합기)

> 서버 없이 웹 브라우저에서 안전하고 빠르게 여러 개의 PDF 파일을 하나로 합쳐주는 웹 애플리케이션입니다.

아름다운 그라데이션 UI와 글래스모피즘(Glassmorphism) 디자인이 적용되어 있으며, **100% 클라이언트 사이드**에서 동작하여 개인정보 및 문서 유출 우려 없이 안전하게 사용할 수 있습니다.

---

## ✨ 주요 기능

- 🔒 **100% 보안 유지 (Client-side Processing)**
  - 업로드한 파일이 외부 서버로 전송되지 않고 브라우저 내부에서만 처리됩니다.
- 🎨 **트렌디한 그라데이션 UI**
  - 부드럽게 움직이는 배경 그라데이션과 깔끔한 카드시각 효과를 제공합니다.
- 📂 **간편한 파일 업로드**
  - 파일 드래그 앤 드롭(Drag & Drop) 및 파일 탐색기 선택을 모두 지원합니다.
- 🗑️ **파일 목록 관리**
  - 병합하기 전 선택한 파일 목록을 확인하고, 필요 없는 파일을 개별 삭제할 수 있습니다.
- ⚡ **무설치 / 무빌드**
  - Node.js나 빌드 도구 없이 `index.html` 단일 파일만 브라우저로 열면 즉시 실행됩니다.

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Library**: [pdf-lib](https://pdf-lib.js.org/) (CDN 연결)

---

## 🚀 사용 방법

1. 본 저장소를 클론(Clone)하거나 `index.html` 파일을 다운로드합니다.
   ```bash
   git clone https://github.com/사용자이름/저장소이름.git
   ```
2. 다운로드한 `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 열어 실행합니다.
3. 병합하고 싶은 PDF 파일들을 드래그하여 놓거나 클릭하여 선택합니다.
4. 파일 목록을 확인한 후 **[PDF 합치기 및 다운로드]** 버튼을 클릭합니다.
5. 병합된 PDF 파일이 자동으로 다운로드됩니다.
