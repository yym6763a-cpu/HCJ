# 🎨 AFK Screen (자리 비움 안내 화면)

> 감각적인 애니메이션 그라데이션과 글래스모피즘(Glassmorphism) 디자인이 적용된 **웹 기반 자리 비움(Away From Keyboard) 안내 스크린**입니다.  
> 자리를 비울 때 현재 일정, 복귀 예정 시각, 남은 카운트다운 및 안내 문구를 깔끔하고 아름답게 표기해 줍니다.

---

## ✨ 주요 기능 (Key Features)

- 🌈 **아름다운 그라데이션 애니메이션**: 백그라운드에서 천천히 움직이는 감각적인 트렌디 컬러 그라데이션
- 💎 **글래스모피즘 UI**: 반투명 유리 느낌의 레이아웃으로 높은 가독성과 모던한 분위기 연출
- 🔤 **강조된 텍스트 레이아웃**: 입력한 **일정(메인 메시지)을 가장 거대하고 명확하게** 표시
- ⏳ **실시간 카운트다운**: 설정한 복귀 시각까지 남은 시간을 초 단위로 실시간 계산하여 출력
- ⚙️ **스마트한 자정 처리**: 복귀 시간이 현재 시간보다 이전일 경우, 자동으로 다음 날 시각으로 계산
- ⚡ **Zero Dependency (단일 파일)**: 별도의 라이브러리 설치나 빌드 과정 없이 `.html` 파일 하나로 즉시 실행

---

## 🖥️ 화면 구성 (Preview Structure)

1. **설정 화면 (Setup Screen)**
   - 일정(메인 메시지) 입력
   - 복귀 예정 시각 선택 (Time Picker)
   - 기타 안내 문구 입력

2. **안내 화면 (Display Screen)**
   - `AWAY FROM DESK` 상태 배지
   - **일정 타이틀** *(최대 폰트 크기)*
   - **복귀 예정 시각** 및 **실시간 남은 시간 카운트다운**
   - 기타 안내 문구
   - 오른쪽 상단 설정 수정(⚙️) 버튼

## 🚀 시작하기 (Getting Started)

별도의 개발 환경이나 웹 서버가 필요하지 않습니다.

### 1. 다운로드 및 실행
```bash
# 레포지토리 클론
git clone https://github.com/your-username/afk-screen.git

# 또는 afk_screen.html 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 실행
```

### 2. 사용 방법
1. `afk_screen.html` 파일을 브라우저로 엽니다.
2. **일정**, **복귀 예정 시간**, **기타 안내 문구**를 입력합니다.
3. **`화면 시작하기`** 버튼을 클릭합니다.
4. 키보드의 **`F11`** 키를 눌러 웹 브라우저를 **전체 화면 모드**로 전환하면 더욱 멋지게 연출됩니다.
5. 내용을 수정하고 싶다면 우측 상단의 **`⚙️ 설정 수정`** 버튼을 누릅니다.

## 🛠️ 기술 스택 (Tech Stack)

- **HTML5**: 구조화된 세맨틱 태그
- **CSS3**: `@keyframes` 애니메이션, Flexbox, `backdrop-filter` (Glassmorphism), `clamp()` 가변 폰트 사이즈
- **JavaScript (ES6+)**: DOM 조작, `setInterval` 기반 실시간 카운트다운 타이머
- **Google Fonts**: [Pretendard](https://github.com/orioncactus/pretendard) (깔끔하고 시독성 높은 CJK 폰트)

---

## 💡 활용 팁 (Tips)

- **모니터 피벗(세로 모드) 활용**: 세로형 모니터에서도 `clamp()` 폰트 반응형 구조 덕분에 레이아웃이 깨지지 않고 아름답게 표현됩니다.
- **다크/라이트 환경 모두 적합**: 고대비의 글래스 카드 디자인을 적용하여 사무실의 밝은 조명 아래나 어두운 환경 모두에서 명확하게 보입니다.
