# ✨ Lorem Ipsum Generator (로렘 입숨 생성기)

> 원하는 글자 수(10자 ~ 5,000자)를 슬라이더로 자유롭게 조절하여 로렘 입숨(Lorem Ipsum) 더미 텍스트를 실시간으로 생성하고 복사할 수 있는 웹 애플리케이션입니다.

## 💡 주요 기능 (Features)

- 🎚️ **실시간 글자 수 조절**: 슬라이더(Slider)를 이동시켜 최소 10자부터 최대 5,000자까지 즉시 반영됩니다. (기본값: 150자)
- 📋 **원클릭 클립보드 복사**: 클릭 한 번으로 생성된 더미 텍스트를 클립보드에 복사하며, 완료 시 토스트 피드백을 제공합니다.
- 🎨 **모던 & 세련된 UI/UX**: 깔끔한 카드 레이아웃, 모던한 폰트, 반응형 디자인이 적용되어 있습니다.
- ⚡ **Zero Dependencies**: 외부 프레임워크나 라이브러리 없이 단 하나의 HTML 파일로 실행 가능합니다.

## 🚀 시작하기 (Getting Started)

별도의 빌드 과정이나 서버 설치가 필요 없습니다.

### 1. 다운로드 및 실행

1. 이 저장소를 클론(Clone)하거나 `index.html` 파일을 다운로드합니다.
```bash
git clone https://github.com/your-username/lorem-ipsum-generator.git
```
2. `index.html` 파일을 마우스로 두 번 클릭하여 임의의 웹 브라우저(Chrome, Edge, Safari 등)에서 실행합니다.

## 🖥️ 사용 방법 (Usage)

1. 페이지에 접속하면 기본적으로 **150자**의 로렘 입숨 문장이 생성되어 있습니다.
2. 상단의 **글자 수 슬라이더**를 좌우로 움직여 글자 수를 원하는 만큼 조절합니다 (10자 ~ 5,000자).
3. 하단의 **`📋 텍스트 복사하기`** 버튼을 눌러 텍스트를 복사한 후, 프로젝트 및 디자인 작업에 붙여넣어 사용합니다.
