# 🌐 Web Utilities & Apps Collection

16가지 유용한 웹 애플리케이션 및 유틸리티 모음집입니다.  
각 프로젝트 폴더 내부의 HTML 실행 파일 경로가 링크되어 있어 GitHub에서 클릭 시 해당 파일 코드로 즉시 이동할 수 있습니다.

- **대표 웹사이트**: [nanalab.kr](https://nanalab.kr)

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3 (Tailwind CSS, Custom CSS), JavaScript (ES6+)
- **Libraries & APIs**:
  - `JSZip` (Docx 및 파일 압축)
  - `PDF.js` & `jsPDF` (PDF 파일 분석/생성)
  - `Mammoth.js` (Docx 텍스트 추출)
  - `FontAwesome` (아이콘)

## 💻 실행 및 사용 방법

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/사용자계정/저장소명.git
   ```
2. 각 프로젝트 폴더로 이동하여 해당 `.html` 파일을 웹 브라우저에서 실행하면 바로 사용할 수 있습니다.
