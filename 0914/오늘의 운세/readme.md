# ✨ 원소로 보는 오늘의 운세 (Element Fortune Teller)

사용자의 기본 정보(**이름, 생년월일, 성별**)와 5가지 원소 속성(**불, 물, 나무, 땅, 바람**) 중 하나를 선택하면, 개성 있는 오늘의 운세와 행운의 요소를 점쳐주는 단일 페이지 웹 애플리케이션(SPA)입니다.

---

## 🌟 주요 기능 (Key Features)

- **사용자 정보 입력**: 이름, 생년월일, 성별 선택 기능
- **원소 속성 선택**: 불(🔥), 물(💧), 나무(🌿), 땅(⛰️), 바람(💨) 중 하나 선택
- **맞춤형 운세 결과 출력**:
  - 원소 기운에 따른 오늘의 운세 메시지
  - 랜덤 운세 점수 (70점 ~ 100점)
  - 행운의 컬러, 행운의 숫자(1~99), 행운의 아이템 제공
- **반응형 웹 디자인**: 모바일, 태블릿, PC 등 다양한 기기 환경에 최적화된 라벤더-보라 파스텔 톤 UI
- **다시 하기 기능**: 입력값을 초기화하고 다시 운세를 점칠 수 있는 리셋 버튼 제공

---

## 🛠 기술 스택 (Tech Stack)

- **HTML5**: 구조화된 웹 폼 및 결과 카드 레이아웃
- **CSS3**: Flexbox, Grid 레이아웃, 파스텔 그라데이션 배경, CSS Animation
- **JavaScript (ES6+)**: DOM 조작, 이벤트 처리, 랜덤 운세 생성 로직

## 🚀 실행 방법 (Getting Started)

별도의 서버 설치나 빌드 과정 없이 웹 브라우저만 있으면 바로 실행할 수 있습니다.

1. 이 저장소를 클론(Clone)하거나 `index.html` 파일을 다운로드합니다.
   ```bash
   git clone https://github.com/your-username/element-fortune-teller.git
   ```
2. 다운로드한 `index.html` 파일을 마우스 우클릭하여 **크롬(Chrome), 엣지(Edge), 사파리(Safari)** 등 원하시는 웹 브라우저로 엽니다.

## 🔮 5대 원소(속성) 정보

| 속성 | 아이콘 | 주요 운세 성향 |
| :--- | :---: | :--- |
| **불 (Fire)** | 🔥 | 열정, 도전, 주도적인 태도, 번뜩이는 아이디어 |
| **물 (Water)** | 💧 | 유연함, 평온함, 직관력, 감수성 회복 |
| **나무 (Wood)** | 🌿 | 성장, 결실, 협동, 새로운 시작과 배움 |
| **땅 (Earth)** | ⛰️ | 신중함, 안정성, 재물운, 성실함과 인정 |
| **바람 (Wind)** | 💨 | 자유로움, 산뜻함, 소통, 순발력과 변화 |
