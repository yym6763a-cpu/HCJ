# ✨ 실시간 글자수 & 바이트(Byte) 계산기

> **트렌디한 글래스모피즘(Glassmorphism) 디자인의 실시간 글자수 및 용량(Byte) 계산 웹 애플리케이션**  
> 한글 2Byte 기준을 완벽하게 지원하며, 복사 및 초기화 기능 등 사용자 편의 기능을 제공합니다.

---

## 🎨 미리보기

- **배경 스타일**: 은은한 보라~핑크 톤의 메쉬 그라데이션
- **UI 스타일**: 반투명 유리 느낌의 글래스모피즘(Glassmorphism)
- **반응형 디자인**: 모바일, 태블릿, PC 화면 완벽 지원

---

## ✨ 주요 기능

- 🎯 **정확한 바이트(Byte) 계산**: 한글 2Byte 규칙을 준수하여 바이트 수 계산
- ⚡ **실시간 연산**: 텍스트 입력/수정과 동시에 결과 즉시 반영
- 📊 **다양한 지표 제공**:
  - 총 용량 (Byte)
  - 총 글자수 (공백 포함)
  - 공백 제외 글자수
  - 총 줄(Line) 수
- 🛠️ **편의 기능**:
  - **텍스트 복사**: 작성한 글을 한 번의 클릭으로 클립보드에 복사
  - **전체 삭제**: 한 번의 클릭으로 입력창 초기화

---

## 📏 바이트(Byte) 계산 기준

| 구분 | 바이트(Byte) | 대상 문자 예시 |
| :--- | :---: | :--- |
| **한글 / 한자 / 전각문자** | **2 Byte** | `가`, `나`, `다`, `韓`, `★` 등 |
| **영문 / 숫자 / 반각 기호** | **1 Byte** | `A`, `z`, `1`, `9`, `!`, `@` 등 |
| **공백 / 줄바꿈** | **1 Byte** | 띄어쓰기(`Space`), 엔터(`\n`) |

## 🚀 사용 방법

 별도의 설치나 서버 설정 없이 브라우저에서 바로 실행할 수 있습니다.

1. 본 저장소의 `index.html` 파일을 다운로드합니다.
2. 다운로드한 `index.html` 파일을 마우스 우클릭 후 웹 브라우저(Chrome, Edge, Safari 등)로 열어 사용합니다.
