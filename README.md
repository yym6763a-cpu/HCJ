# 🚀 Web Development Portfolio & Utilities Collection

웹 개발 학습 과정부터 다양한 프론트엔드 포트폴리오 스타일, 여행 가이드, 그리고 웹 유틸리티 앱 컬렉션까지의 기록을 담은 저장소입니다.

---

## 📌 Project Overview

본 저장소는 **HTML, CSS, JavaScript**를 바탕으로 한 단계별 웹 프로젝트 모음집입니다.  
서버 전송 없이 **100% 브라우저(Client-Side) 환경**에서 동작하는 가볍고 빠른 웹 애플리케이션 및 다양한 디자인 스펙트럼의 포트폴리오를 포함하고 있습니다.

---

## 📅 Project History & Timeline

일자별 프로젝트 진행 및 업데이트 현황입니다.

| 날짜 | 프로젝트 / 작업명 | 상세 내용 |
| :--- | :--- | :--- |
| **07.23** | **Portfolio Web v1** | **블루 카드 & 섹션형 포트폴리오**<br>• 네비게이션 바와 신뢰감 있는 블루 히어로 헤더<br>• 대표 비디오 재생기(Media) 및 섹션별 카드 레이아웃 구조 |
| **07.24** | **Portfolio Web v2** | **클래식 표 & 텍스트 이력서 (Resume)**<br>• 정석적인 전통 이력서 형태의 깔끔하고 가독성 높은 구조<br>• 프로필 사진, 인적사항 표 및 국/영문 자기소개 중심 |
| **07.27** | **Portfolio Web v3** | **3열 파스텔 모던 그리드 (Profile)**<br>• 3컬럼(Column) 파스텔 톤 모던 레이아웃<br>• 언어 능력 그래프 바, 역량 태그(Pills), 스킬 아이콘 그리드 |
| **07.28** | **JS 기초 실습** | JavaScript 핵심 개념 및 DOM 조작 기초 구현 |
| **07.29** | **부산 가이드 웹페이지** | 부산 지역 대표 관광지 및 코스 안내 페이지 |
| **08.31** | **여행 가이드 시리즈** | • 경주 MT 2박 3일<br>• 경주 1박 2일 팀 MT<br>• 부산 여행 3박 4일<br>• 한국 3박 4일 여행 가이드 |
| **09.01** | **Interactive Web Apps** | • 무인도 생존 성향 테스트<br>• 웹 설문조사 애플리케이션 |
| **09.07** | **K-여행 (K-Tabi)** | 외국인 및 관광객을 위한 한국 여행 안내 플랫폼 |
| **09.14** | **Web Utilities & Apps Collection** | 생산성 도구 및 다양한 클라이언트 웹 유틸리티 앱 통합 모음집 |

---

## 🛠 Tech Stack

### Frontend
- **Language**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Responsive Design, Flexbox/Grid, CSS Variables, Tailwind CSS
- **Features**: Client-Side Rendering (CSR), DOM Manipulation, LocalStorage API

---

## Key Highlights

1. **다양한 스타일의 포트폴리오 구축 (07.23 ~ 07.27)**
   - **07.23 (v1)**: 네비게이션과 미디어 영역을 포함한 **체계적인 카드형 웹 포트폴리오**
   - **07.24 (v2)**: 인적사항 표와 국/영문 자기소개에 집중한 **클래식 이력서(Resume)**
   - **07.27 (v3)**: 파스텔 톤 컬러와 그래프 바, 아이콘 그리드를 활용한 **3열 모던 프로필**

2. **실용적인 여행 가이드 플랫폼 (07.29 / 08.31 / 09.07)**
   - 국내 주요 여행지(부산, 경주) 및 국내외 관광객을 위한 반응형 안내 웹페이지를 제작했습니다.

3. **인터랙티브 콘텐츠 & 웹 유틸리티 (09.01 / 09.14)**
   - 심리/성향 테스트, 설문 조사부터 서버 없이 작동하는 유용한 웹 유틸리티 모음집까지 구현했습니다.
