# K-旅 (K-Tabi) : 韓国旅行完全ナビ (한국 여행 완전 가이드)

日本人旅行者が韓国をスムーズかつ快適に旅行できるよう設計された、実用的な二重言語対応(日本語 / 한국어)ワンページWebガイドです。

---

## 1. プロジェクト概要

- 対象ユーザー: 韓国旅行を計画中または現地旅行中の日本人観光客、および日本人旅行者を案内・サポートする韓国人ユーザー
- 主要コンテンツ:
  - 交通・決済（T-money / WOWPASS / 気候同行カードの徹底比較）
  - 地図アプリの注意点（NAVERマップの必要性）
  - エリア別スポット（実写写真付き: 聖水洞、弘大、明洞、益善洞、ザ・現代ソウル、広蔵市場）
  - 旅の必須韓国語フレーズ（日本語・ハングル・カタカナ発音・ワンクリックコピー）
  - リアルタイム簡易為替計算機 (KRW <-> JPY)
  - 緊急・サポート窓口（24時間日本語対応 1330案内、112/119、Tax Refund）
  - 二重言語(i18n)切替機能（日本語 / 한국어 リアルタイム切替 & localStorage保存）

## 3. 使用技術スタック

- HTML5: セマンティック構造（header, nav, main, section, article, footer, data-i18n属性）
- CSS3: CSSカスタムプロパティ（CSS Variables）、カードズームホバー、スムーズトランジション
- Tailwind CSS (v3 CDN): レスポンシブグリッド、余白、タイポグラフィの最適化
- Font Awesome 6 (Webfont CDN): 絵文字（Emoji）を一切使わない高品質ベクターアイコン
- JavaScript (ES6+): クリップボードAPI、localStorage状態保持、リアルタイム双方向為替計算
- jQuery (v3.7.1 CDN): i18nテキスト自動マッピング、イベントデリゲーション、スライドメニュー、タブフィルタリング

## 4. 10年目ウェブパブリッシャーによる設計ポイント（チューター解説）

### (1) クライアントサイド i18n (多言語) アーキテクチャ
- `data-i18n` 属性による宣言的データバインディングを採用し、DOM構造を変更することなく瞬時に日本語と韓国語を切り替えます。
- ユーザーが選択した言語は `localStorage` に保存され、ページをリロードしても前回の選択状態（日本語 or 한국어）が自動で維持されます。
- 言語切り替え時に `<html lang="ja">` または `<html lang="ko">` を動的に更新し、ブラウザのフォントレンダリングやスクリーンリーダーの音声言語を最適化します。

### (2) 実写写真の視覚的演出とパフォーマンス
- 各スポットカードに実際の高品質な韓国観光写真（聖水、弘大、明洞、韓屋、現代百貨店、広蔵市場）を配置。
- CSSの `overflow: hidden` と `transform: scale(1.07)` によるマイクロアニメーションで、マウスホバー時に心地よい奥行き感を演出しています。
- 全ての画像に `loading="lazy"` を付与し、初期ロード時の通信負荷とトークン消費を抑えています。

### (3) 絵文字（Emoji）を排した洗練されたUI
- OS環境やデバイスごとに表示揺れが発生しやすい絵文字の代わりに、Font Awesomeの統一されたアイコンシステムを採用。視認性とプロフェッショナルな品質を担保しています。
