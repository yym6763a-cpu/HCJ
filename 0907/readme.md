# K-여행 (K-Tabi) : 일본인 맞춤형 한국 여행 완전 가이드

일본인 관광객이 한국을 쉽고 편리하게 여행할 수 있도록 설계된 반응형 단일 페이지(One-page) 웹 가이드 프로젝트입니다. 일본어와 한국어 이중언어(i18n)를 완벽하게 지원합니다.

> 프로젝트 규칙 및 기본 프롬프트 정의는 [GEMINI.md](GEMINI.md)에서 확인하실 수 있습니다.

---

## 1. 프로젝트 개요

- 목적: 한국을 방문하는 일본인 여행객을 위한 실질적인 여행 정보 제공 및 의사소통 지원
- 주요 사용자:
  - 한국 여행을 준비하거나 여행 중인 일본인 관광객
  - 일본인 친구 또는 고객에게 한국 여행 코스 및 편의 정보를 안내하는 한국인
- 핵심 콘텐츠:
  - 대중교통 및 결제 수단 (T-money / WOWPASS / 기후동행카드 장단점 비교)
  - 한국 내비게이션 필수 팁 (네이버 지도 활용법 안내)
  - 서울 대표 핫플레이스 (실사 사진 수록: 성수동, 홍대, 명동, 익선동, 더현대 서울, 광장시장)
  - 여행 필수 실전 한국어 회화 (카타카나 발음 표기 및 원클릭 복사 기능)
  - 원/엔 실시간 간이 환율 계산기 (KRW <-> JPY)
  - 긴급 상황 지원 연락처 (24시간 다국어 1330 안내, 112/119, 사후면세 제도)
  - 이중언어 전환 시스템 (한국어 / 日本語 실시간 전환 및 상태 저장)

## 3. 기술 스택

- Markup: HTML5 (Semantic elements, WAI-ARIA, data-i18n 속성)
- Styling:
  - CSS3 (CSS Variables, Flexbox, Grid, CSS Transition)
  - Tailwind CSS (v3 CDN 기반 유틸리티 퍼스트 레이아웃)
  - Font Awesome 6 (No-Emoji 원칙에 기반한 벡터 웹폰트 아이콘)
- Script:
  - Vanilla JavaScript (ES6+, Clipboard API, localStorage)
  - jQuery (v3.7.1 CDN, DOM 제어, 탭 필터링, 스무스 스크롤)

## 4. 10년 차 웹 퍼블리셔 겸 튜터의 설계 및 강의 노트

### (1) 클라이언트 사이드 i18n(다국어) 전환 아키텍처
- 별도의 페이지 분리 없이 단일 HTML 파일에서 `data-i18n` 속성을 매개로 한국어와 일본어를 즉각 치환합니다.
- 사용자의 언어 선택은 `localStorage`에 저장되어 페이지 새로고침 시에도 이전 언어 환경이 유지됩니다.
- 언어 변경 시 `<html lang="ko">` 또는 `<html lang="ja">`로 동적 반영되어 웹 브라우저의 기본 서체 렌더링 및 음성 스크린 리더(Accessibility) 지원을 보장합니다.

### (2) 시맨틱 마크업과 웹 접근성 (A11y)
- `header`, `nav`, `main`, `section`, `article`, `footer`를 명확히 분리하여 문서의 의미 구조를 완성했습니다.
- 모바일 햄버거 메뉴 및 탭 버튼에 `role="tablist"`, `aria-expanded` 속성을 명시하여 보조 기술 기기 호환성을 높였습니다.
- 키보드 탭 탐색 사용자를 위해 `style.css`에 `:focus-visible` 전용 아웃라인 링을 정의했습니다.

### (3) Tailwind CSS와 커스텀 CSS의 역할 분담
- 레이아웃 구성, 패딩, 마진, 반응형 브레이크포인트는 Tailwind CSS 유틸리티 클래스로 빠르게 작업하여 코드 생산성을 확보했습니다.
- 호버 리프트 효과, 고화질 사진 줌 애니메이션, 토스트 알림 컴포넌트 스타일 등은 [assets/css/style.css](assets/css/style.css)에 모듈화하여 스타일 결합도를 낮추고 유지보수성을 극대화했습니다.

### (4) 실사 사진 활용과 로딩 최적화
- 명소 카드마다 실사 사진을 적용하고 `loading="lazy"` 속성을 부여하여 초기 로딩 속도와 통신 자원을 절약했습니다.
- 히어로 섹션에는 어두운 반투명 그래디언트 오버레이를 씌워 배경 사진의 웅장함을 살리면서도 텍스트의 대비(명도비)를 유지했습니다.

### (5) 안정적인 jQuery 이벤트 위임(Event Delegation)
- 회화 문장 복사 기능은 `$(document).on('click', '.btn-copy', ...)` 형태의 이벤트 위임 패턴을 사용하여 추후 비동기로 회화 카드가 추가되더라도 이벤트 리스너를 재등록할 필요가 없습니다.

## 5. 日本語の概要 (Japanese Summary)

本プロジェクトは、日本人観光客向けに交通・人気スポット・必須韓国語フレーズ・為替計算機を提供するWebサイトです。
右上の「日本語 / 한국어」トグルボタンで言語を自由に切り替えることができます。
ブラウザで `index.html` を開くだけで全機能をお使いいただけます。
