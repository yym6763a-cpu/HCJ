# 📊 GAS 기반 인터랙티브 웹앱 컬렉션

Google Apps Script(GAS)와 Google Sheets API를 연동하여 제작한 **인터랙티브 웹 애플리케이션 모음**입니다.  
별도의 서버 구축 없이 구글 클라우드 인프라를 활용하여 실시간 데이터 수집, 자동화 및 반응형 UI를 제공합니다.

---

## 📂 프로젝트 구성

이 리포지토리는 목적에 따라 두 가지 웹 애플리케이션으로 구성되어 있습니다:

1. **🏝️ 무인도 생존 성향 테스트** (스낵형 인터랙티브 심리테스트)
2. **🎓 교육 만족도 설문조사** (피드백 수집 및 분석용 웹앱)

---

## 1. 🏝️ 무인도 생존 성향 테스트

스모어(Smore) 스타일의 몰입형 4지선다 인터랙티브 심리테스트 웹앱입니다.

### 📌 주요 기능
- **스토리형 문답 UX**: 무인도 조난 상황을 배경으로 한 4단계 돌발 질문 구성
- **실시간 성향 판별 알고리즘**:
  - 🧠 **치밀한 전략가 (Brain Master)**: 분석 및 기지 구축형
  - 🛠️ **야생의 행동파 (Wild Builder)**: 손재주 및 실전 도구 제작형
  - 🔥 **불굴의 생존 탐험가 (Signal Keeper)**: 구조 신호 및 희망 중심형
- **시트 자동 기록**: 참여자 닉네임, 판별된 생존 유형, 이메일, 일시 저장

---

## 2. 🎓 교육 만족도 설문조사

교육 종료 후 수강생의 피드백을 체계적으로 수집하는 설문조사 웹앱입니다.

### 📌 주요 기능
- **모던 반응형 디자인**: Tailwind CSS 및 Material Symbols 기반의 직관적인 UI/UX
- **상태 기반 인터랙션**: 문항 응답에 따른 상단 실시간 진행률(Progress Bar) 표시
- **데이터 자동 변환 & 검증**:
  - 필수 입력값 검증 및 이중 제출 방지 로딩 처리
  - 점수형 척도(1~5점)를 백엔드에서 텍스트(예: `매우 만족`, `그렇다`)로 자동 변환 후 스프레드시트에 저장
- **데이터 수집 항목**:
  - 기본 정보 (성명, 이메일)
  - 5점 척도 만족도 평가 (전반적 만족도, 이해도, 실무 활용도)
  - 주관식 서술형 의견 (유익했던 점, 건의사항 및 교수님께 전하는 말)
