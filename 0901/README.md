# 🎓 교육 만족도 설문조사 웹앱

Google Apps Script(GAS)와 구글 스프레드시트를 연동하여 제작한 **반응형 교육 만족도 설문조사 웹 애플리케이션**입니다.  
사용자 친화적인 인터페이스와 즉각적인 데이터 검증, 그리고 실시간 스프레드시트 기록 기능을 제공합니다.

---

## 📌 주요 기능

1. **사용자 경험(UX) 최적화 인터페이스**
   - Tailwind CSS 및 Google Material Symbols 기반의 깔끔하고 현대적인 디자인
   - 상단 실시간 진행률(Progress Bar) 표시로 설문 몰입도 향상
   - 라디오 버튼 선택 시 인터랙티브한 UI 하이라이트 효과

2. **유효성 검증 (Validation)**
   - 필수 항목(성명, 이메일, 객관식 만족도 문항) 미입력 시 직관적인 에러 알림 제공
   - 이중 제출 방지를 위한 로딩 상태 처리 (`제출 중...` 버튼 비활성화)

3. **자동 데이터 변환 및 시트 기록**
   - 백엔드(GAS)에서 점수형 척도(1~5점)를 직관적인 한글 응답 텍스트(예: `매우 만족`, `그렇다` 등)로 자동 변환 후 스프레드시트에 행(Row) 추가

4. **설문 완료 및 리셋**
   - 제출 완료 시 완료 화면으로 전환되며, '홈으로 돌아가기' 클릭 시 입력 폼 초기화

## 📋 설문 항목 및 데이터 구조

스프레드시트에 저장되는 데이터 열(Header) 구조는 다음과 같습니다:

| 열(Column) | 항목명 | 설명 및 예시 |
| :---: | :--- | :--- |
| **A** | **성명** | 참여자 이름 (필수) |
| **B** | **이메일** | 참여자 이메일 주소 (필수) |
| **C** | **전반적 만족도** | 매우 만족 ~ 매우 불만족 (필수) |
| **D** | **내용 이해도** | 매우 그렇다 ~ 전혀 그렇지 않다 (필수) |
| **E** | **학습/업무 도움 여부** | 매우 그렇다 ~ 전혀 그렇지 않다 (필수) |
| **F** | **가장 유익했던 부분** | 주관식 서술형 (선택) |
| **G** | **의견 및 건의사항** | 교수님께 전하고 싶은 말 / 건의사항 (선택) |

## 🚀 설치 및 배포 방법

1. **구글 스프레드시트 준비**
   - 새 구글 스프레드시트를 생성하고 위 데이터 구조에 맞게 1행 헤더를 구성합니다.
   - 스프레드시트 URL에서 고유 ID를 확인합니다.

2. **Apps Script 프로젝트 생성**
   - 스프레드시트 메뉴에서 **확장 프로그램 > Apps Script**로 이동합니다.
   - `Code.gs`에 백엔드 코드를 붙여넣고, `SPREADSHEET_ID` 변수에 본인의 시트 ID를 입력합니다.
   - 좌측 상단 **+ (파일 추가) > HTML**을 클릭하여 `index.html`을 생성하고 프론트엔드 코드를 붙여넣습니다.

3. **웹앱 배포**
   - 우측 상단 **배포 > 새 배포** 클릭
   - 유형 선택: **웹 앱(Web App)**
   - **다음 사용자 권한으로 실행**: `나(내 계정)`
   - **액세스 권한이 있는 사용자**: `모든 사용자(Anyone)`
   - 생성된 웹 앱 URL을 복사하여 설문 대상자에게 공유합니다.

# 🏝️ 무인도 생존 성향 테스트

Google Apps Script(GAS)와 Google Sheets를 연동하여 제작한 스낵형 인터랙티브 심리테스트 웹앱입니다.

## 📌 주요 기능
- **반응형 웹 UI**: 모바일/데스크톱 환경에 최적화된 설문 화면
- **성향 분석 로직**: 4가지 돌발 상황 선택지에 따른 실시간 성향(전략가, 행동파, 희망 탐험가) 분류
- **스프레드시트 DB 연동**: 참여자 이름, 성향 분석 결과, 이메일, 제출 일시 자동 기록

## 🛠️ 기술 스택
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Backend & DB**: Google Apps Script (GAS), Google Sheets API

## 🚀 설치 및 배포
1. 구글 스프레드시트 생성 후 `확장 프로그램` > `Apps Script` 진입
2. `Code.gs` 및 `index.html` 파일 추가
3. `Code.gs`의 `SPREADSHEET_ID` 변수에 본인 시트 ID 입력
4. **배포** > **새 배포** > 유형: **웹 앱** 선택 후 배포 URL 생성
